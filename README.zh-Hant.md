# RuneLearn · 洛克文識記與轉換

[简体中文](README.md) · **繁體中文** · [English](README.en.md) · [日本語](README.ja.md)

[線上使用RuneLearn](https://sysgrapes.github.io/RuneLearn/)

歡迎來到 **RuneLearn**——一款幫你輕鬆識記洛克文、又充滿趣味的小工具。

在這裡，英文字母會被顯示成一套獨特的「洛克文」字形。你可以把它當成一款記錄與轉換的小應用，也可以把它當成一套寓教於樂的背單字小工具，雖然效果肯定一般。整個工具完全離線執行，打開就能用，不需要連網。

## 它主要能做什麼

RuneLearn 分為兩大功能板塊，在頁面頂端即可切換：

### 一、洛克文轉換

把你輸入的英文文字，轉換成好看的「洛克文」字形，並支援自訂樣式：

- 輸入文字後，下方即時顯示轉換效果，支援多行文字；
- 可自由調整**字形顏色**、**描邊顏色**和**描邊粗細**；
- 也可切換回「正常」字形，方便對比一般文字與洛克文的差別；
- 一鍵匯出**透明背景的 PNG 圖片**，方便你保存、分享到聊天或配圖使用。

### 二、洛克文識記

把學習變成遊戲，邊看邊猜，邊記邊練。內含兩個子板塊：

- **認字母**：隨機顯示一個洛克文字母，你在輸入框裡寫下對應的英文字母即可。大小寫都可以，答對答錯會即時給你回饋。
- **認單字**：選擇難度後，隨機顯示一個洛克文單字，你拼出對應的英文單字。除了判定對錯，還會顯示這個單字的**讀音、詞性和中文釋義**，幫你真正記住它。

兩道題的作答都很順暢：

- 輸入後點「確定」或直接按 Enter 即可送出，立刻看到對錯；
- 答完想換一題，點「繼續」（或「換一題」）即可進入下一題；
- 答對或答錯時，最近的一筆紀錄會以顏色閃爍一下，一眼就能看出這題答得如何。

## 一些設計

- **四種介面語言**：简体中文、繁體中文、English、日本語。第一次打開網站時，頁面會彈出一個語言選擇框，選好之後立刻生效、以後不再打擾；之後想換語言，隨時在**頁面最底部**切換即可。
- **每種語言都有自己的字型**：簡體與英文用敦敦體，繁體用台灣常見的黑體，日文用日本常用黑體（如 Noto Sans JP），並逐級回退到系統字型；首次彈窗裡四種語言同屏顯示時，每段文字也各用各的字型。
- **V 與 W 長得一樣**：在這套字形裡，V 和 W 顯示完全相同。所以**認字母**時只要遇到 V 或 W，兩者都算正確，不必糾結。但是**認單字**時還是要多加留意哦。
- **記單字分難度**：為認單字板塊準備了由易到難的多檔難度，從短詞慢慢過渡到更長、更有挑戰的單字，循序漸進。
- **歷史紀錄都在本機**：你答過的每一題都會自動保存下來，關閉頁面也不會丟，下次打開還能接著看。認字母和認單字各有獨立的紀錄，需要時可以一鍵清除。

## 怎麼開始用

拿到整個 `runelearn` 資料夾後，直接雙擊裡面的 `index.html` 打開即可使用，無需安裝、無需連網。你也可以把整個資料夾壓縮打包，隨時隨地分享給朋友一起玩。也可以前往 Github Pages 頁面遊玩。

也可以[點這裡](https://sysgrapes.github.io/RuneLearn/)線上使用。
