# RuneLearn · 洛克文识记与转换

**简体中文** · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md)

[在线使用RuneLearn](https://sysgrapes.github.io/RuneLearn/)

欢迎来到 **RuneLearn**：一款帮你轻松识记洛克文、又充满趣味的小工具。

在这里，英文字母会被显示成一套独特的「洛克文」字形。你既可以把它当成一款记录与转换的小应用，也可以把它当成一套寓教于乐的背单词小工具，虽然效果肯定一般。整个工具完全离线运行，打开就能用，不需要联网。

## 它主要能做什么

RuneLearn 分为两大功能板块，在页面顶部即可切换：

### 一、洛克文转换

把你输入的英文文字，转换成好看的「洛克文」字形，并支持自定义样式：

- 输入文字后，下方即时显示转换效果，支持多行文字；
- 可自由调整**字形颜色**、**描边颜色**和**描边粗细**；
- 也可切换回「正常」字形，方便对比普通文字与洛克文的差别；
- 一键导出**透明背景的 PNG 图片**，方便你保存、分享到聊天或配图使用。

### 二、洛克文识记

把学习变成游戏，边看边猜，边记边练。内含两个子板块：

- **认字母**：随机展示一个洛克文字母，你在输入框里写下对应的英文字母即可。大小写都可以，答对答错会即时给你反馈。
- **认单词**：选择难度后，随机展示一个洛克文单词，你拼出对应的英文单词。除了判定对错，还会展示这个单词的**读音、词性和中文释义**，帮你真正记住它。

两道题的作答都很顺畅：

- 输入后点「确定」或直接按回车即可提交，立刻看到对错；
- 答完想换一题，点「继续」（或「换一个」）即可进入下一题；
- 答对或答错时，最近的一条记录会以颜色闪烁一下，一眼就能看出这题答得如何。

## 一些设计

- **四种界面语言**：简体中文、繁體中文、English、日本語。第一次打开网站时，页面会并弹出一个语言选择框，选好之后立刻生效、以后不再打扰；之后想换语言，随时在**页面最底部**切换即可。如果想直接进入某种语言的界面，也可以访问主页址后追加 `/zh/`、`/zh-hant/`、`/en/`、`/ja/` 的专属链接，打开即是对应语言。
- **每种语言都有自己的字体**：简体与英文用敦敦体，繁体用台湾常见的黑体，日文用日本常用黑体（如 Noto Sans JP），并逐级回退到系统字体；首次弹窗里四种语言同屏展示时，每段文字也各用各的字体。
- **V 与 W 长得一样**：在这套字形里，V 和 W 显示完全相同。所以**认字母**时只要遇到 V 或 W，两者都算正确，不必纠结。但是**认单词**时还是要多多留意哦。
- **记单词分难度**：为认单词板块准备了由易到难的多档难度，从短词慢慢过渡到更长、更有挑战的单词，循序渐进。
- **历史记录都在本地**：你答过的每一题都会自动保存下来，关闭页面也不会丢，下次打开还能接着看。认字母和认单词各有独立的历史，需要时可以一键清空。

## 怎么开始用

拿到整个 `runelearn` 文件夹后，直接双击里面的 `index.html` 打开即可使用，无需安装、无需联网。你也可以把整个文件夹压缩打包，随时随地分享给朋友一起玩。也可以前往 Github Pages 页面游玩。
